7 使用tidymodels构建线性回归模型

代码 
lm_spec <- linear_reg() |>
  set_engine("lm") |>
  set_mode("regression")

lm_fun <- \(data) {
  recipe(y ~ x1 + x2, data = data) |>
    step_normalize(x1) -> rec # 添加预处理步骤

  workflow() |>
    add_recipe(rec) |>
    add_model(lm_spec) |>
    fit(data)
}

7.1 拟合与合并

代码 
data_nest |>
  mutate(fit = map(data, \(x) map(x, lm_fun))) |>
  mutate(pool = map(fit, pool)) |>
  mutate(tidy = map(pool, \(x) tidy(x, conf.int = TRUE))) |>
  select(group, tidy) |>
  unnest(cols = tidy) -> result

result
1
第一个map对每行应用函数，第二个map对该列表中的每个数据集应用函数
2
对每组的列表可以直接用pool函数
3
tidy函数可以直接应用于pool结果
